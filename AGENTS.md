# Repository Instructions

- Run Python scripts and modules using `uv run ...` (e.g., `uv run python <script.py>` or `uv run python -m <module>`).
- Track tasks in `docs/todos.md`. When asked to work on a task from the todo list, pick up the next unchecked item (`- [ ]`) one at a time, and mark it as done (`- [x]`) upon completion.
